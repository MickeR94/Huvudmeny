# Huvudmeny

### About this assignment

This is a program that runs in the console and serves as an exercise in using switch-statements, for-loops, while-loops, parsing strings. It also helps me familiarize with the C# syntax.
The program gives the user 5 options:
0. Exit <-- Close the program
1. Youth or retiree <-- Enter the age of a movie theater visitor to see what their visit costs (discount if they're below the age of 20 or above the age of 64)
2. Calculate price for a group <-- Calculate the price for a group of visitors by entering the number of people as well as their respective age
3. Type a random word for a surprise (or just see it 10x) <-- The user can enter a random word in the terminal and it is printed back to them 10 times
4. Type a random sentence, three words minimum <-- the third word is selected and printed back in the terminal


In its current state, the program works okay, but the while-loop functionality is not flawless. I'd like the program to keep running until option 0 is chosen. If any other option is chosen, they should return back to the main menu once they're done with that option.

Furthermore, it would be beneficial with more error handling.
